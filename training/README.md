# Inherited teaching fixtures

source/ contains the 0.3 program lessons retained by 0.4. semantic/ contains the 0.4 same-contract scalar preferences, obligations and protocol repairs. These files are inputs retained for audit, not new 0.5 model results. Historical compiler hashes, solver results, packet IDs and version labels may refer to their original release. Re-run the generator/checker for a new admission record; do not silently relabel old receipts.

No model was trained. Answers and oracles are included and are not secret held-out data. Some older static contrast lessons change their API or meaning, so do not reward them as contract-preserving repairs. The tools under tools/ regenerate the applicable source/semantic fixtures at these new paths.
