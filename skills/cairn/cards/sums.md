# The sums card

Sent to an agent when the program uses `match`, `try`. Codes: `E-ENUM-VARIANT`, `E-MATCH-BINDING`, `E-MATCH-COVERAGE`, `E-MATCH-DUPLICATE`, `E-MATCH-TYPE`, `E-SUM-ARITY`, `E-SUM-PAYLOAD`, `E-TRY`, `E-VARIANT-AMBIGUOUS`.

```text
enum Parsed {Ok(Header); Short(usize); Empty;} is a tagged sum, enum Result[T, E] {Ok(T); Err(E);} a generic one; payloads are any value type. Parsed.Short(n) may be written Short(n) where the sum is expected (return, typed let, assignment, argument, ==), unless a local, constant, function or type has that name (E-VARIANT-AMBIGUOUS). match p { Ok(h)=>return h.size; Short(n)=>return 0; Empty=>{ n = 0; } } has exactly one arm per variant, no wildcard (E-MATCH-COVERAGE); an arm names a variant of the subject and is a block or one return, break, continue, assignment or call; binders are fresh, immutable, local to the arm; the subject is evaluated once; matching an owner consumes it. A sum is copyable if its payloads are; no heap allocation, no unchecked payload access. try x on a two-variant sum (success first) yields the success payload or returns the failure from the enclosing function, whose return type is a two-variant sum with the same failure payload (E-TRY). It is the only propagation form; nothing unwraps implicitly, and f(x); may not drop such a sum (E-DISCARD): try f(x); or let _ = f(x);. Err(_) and for _ bind nothing; a linear payload is never _ (E-LINEAR-LEAK). Foreign callers must supply a valid tag and its initialized payload.
```
