# The commands card

A host or the command line names this card in a refusal. Codes: E-EXPORT E-EXPORT-TAMPERED E-EXPORT-TOOLCHAIN E-PROJECT-OR-ENVIRONMENT E-RULE E-TARGET E-TARGET-FEATURE E-TARGET-MISMATCH E-TARGET-TOOLKIT.

```text
cairn prints a JSON record when piped and text at a terminal. E-PROJECT-OR-ENVIRONMENT, status unknown, says what a manifest, a path, an option or a tool of this machine lacks; it is no verdict on the program. A device target is sm_ and a compute capability with an optional f or a suffix, sm_120, from --device-target, [build] device_target or the one kind of GPU present (E-TARGET); what needs a feature the target lacks is E-TARGET-FEATURE, a record made for another target E-TARGET-MISMATCH, and a build needs an nvcc that compiles the target (E-TARGET-TOOLKIT). build, run and test check an export first: a directory that is none is E-EXPORT, a changed, added or removed file or an edited record E-EXPORT-TAMPERED, another compiler E-EXPORT-TOOLCHAIN. cairn rules takes a diagnostic code, a card's name or a source path, else E-RULE.
```
