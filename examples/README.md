# Examples

Every project here is built and run by the test suite. Commands are written as `cairn ...`; from a source checkout that is `python3 bin/cairn ...`.

Start with [hello](hello) if you want the smallest complete project, [apps/kvstore](apps/kvstore) if you want to see how a real program is shaped, and [../docs/guide/tour.md](../docs/guide/tour.md) if you want the language in twelve programs.

| project | what it is | command |
| --- | --- | --- |
| [hello](hello) | the smallest project: a manifest, two modules, one task contract | `cairn run examples/hello` |
| [systems](systems) | a decimal parser and a counting sort, with contracts for both | `cairn test examples/systems` |
| [basics](basics) | three single-file sources with no `main`, used by the harnesses | `cairn check examples/basics/native.cairn` |
| [apps/kvstore](apps/kvstore) | a crash-safe log-structured store with an in-memory index | `cairn run examples/apps/kvstore` |
| [apps/service](apps/service) | a TCP key/value service on a line protocol | `cairn run examples/apps/service` |
| [apps/analytics](apps/analytics) | a columnar engine whose table types are generated by recipes | `cairn run examples/apps/analytics` |
| [apps/simulator](apps/simulator) | one Jacobi stencil, three back ends, bitwise agreement | `cairn run examples/apps/simulator` |
| [apps/gpu_pipeline](apps/gpu_pipeline) | upload, map, compact, reduce, download, checked against the host | `cairn run examples/apps/gpu_pipeline` |
| [embedded](embedded) | a bare-metal AArch64 image under QEMU, and a guard violation | `cairn run examples/embedded` |
| [proof_scope](proof_scope) | what `cairn verify` covers and what it cannot reach | `cairn verify examples/proof_scope/reference.cairn examples/proof_scope/candidate.cairn --all` |
| [sketch](sketch) | a host-bound sketch settled by SMT, with no model in the loop | `python3 tools/ai/sketch_demo.py` |
| [agent](agent) | the fixture behind the edit and repair loop | `python3 tools/ai/demo.py` |

`apps/simulator`, `apps/gpu_pipeline` and `apps/analytics/gpu.toml` need nvcc and a CUDA device. `embedded` needs `qemu-system-aarch64` on an AArch64 host. Everything else needs only a C++20 compiler.
