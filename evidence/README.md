# Evidence versions

`v0_6/` contains this release's current code, arithmetic-certificate, coverage, native, sanitizer, context and installation results. `v0_6/summary.json` is the entry point. `v0_5/` (formerly the root of this directory, names unchanged) is **0.5 historical evidence**, not fresh 0.6 measurements. Their original names and source identity are preserved. No old result confers verification on a new source.
